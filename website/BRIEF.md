# ACTA presentation website — build brief

Approved order: website first, then the approved final video. Local Windows delivery; no public hosting migration or submission.

## Audience and promise

Bank branch staff are the product users. Bank hackathon judges are the website visitors. The first screen must say both what ACTA does and who operates it: "Revisión documental para el personal de sucursal". Main idea: "Que la próxima visita resuelva el pendiente." A customer returning should not erase prior reviewed work. The strongest moment is the before/after of the same case: retain reviewed identity, explicitly replace a conflicting address document, add income evidence, retain both reviews.

Update 2026-09-10 (user-approved): the official Caja de Ahorros logo (assets/caja-de-ahorros-logo.png, unmodified, provenance in assets/PROVENANCE.md) is shown alongside "Reto presentado por", with the exact independent-submission / no-affiliation wording; it must not read as an ACTA×Caja partnership lockup.

Both bright natural daylight, navy/white office palette, warm paper and wood, plausible modest contemporary branch in Panama. No visible brands, text, real records or generated software UI. Each visibly captioned as a generated conceptual scene. Use readable authored HTML for documentary details. Root will supply assets; build initially with a intentional CSS document composition if missing, no broken images.
